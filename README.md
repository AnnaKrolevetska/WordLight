## Про проєкт

**WordLight** — християнський застосунок для iPhone, який допомагає вивчати англійську мову на основі Біблії: від простих слів рівня A1 до самостійного читання Святого Письма англійською.

Назва та логотип (розкрита книга з вогником) — відсилка до вірша *«Слово Твоє — світильник для ніг моїх»* (Пс. 119:105).

Цей репозиторій містить **інтерактивне веб-прев'ю** застосунку в рамці iPhone. Його можна гортати й натискати, як справжній застосунок.

## Що вміє

- **Онбординг** — ім'я, рідна мова, рівень англійської (або короткий тест), мета, щоденна ціль, персональний маршрут.
- **Home** — вірш дня з озвученням, урок на сьогодні, слова для повторення, щоденна ціль і серія днів.
- **Learn** — рівні A1–C1, модулі та уроки. Урок: знайомство зі словами → вправи → читання вірша → короткий тест → підсумок.
- **Вправи** — вибір перекладу, вибір слова, заповнення пропуску, введення слова, поєднання пар.
- **Повторення** — інтервальне повторення з оцінками Again / Hard / Good / Easy.
- **Bible** — історії, книги, теми й рівні. Натискання на будь-яке слово відкриває його картку; перемикач між простим переказом і оригінальним текстом.
- **Words** — особистий словник: усі, у процесі, вивчені, збережені.
- **Profile** — статистика тижня, налаштування, підписка WordLight Plus (демо).

## Контент

- Курс **A1**: 3 модулі × 4 уроки, **90 слів** з українським перекладом, транскрипцією та прикладами.
- Модулі: *God & Creation*, *People & Family*, *Love & Kindness*.
- Біблійні цитати — дослівний текст **King James Version** (суспільне надбання). Прості перекази позначені як *Adapted*, навчальні речення — як *Example*.
- Фото — [Unsplash](https://unsplash.com/license) (безкоштовна ліцензія).

## Запуск

**Локально:** відкрийте `index.html` у браузері.

**На Vercel:**
1. [vercel.com](https://vercel.com) → **Add New → Project → Import** цього репозиторію.
2. Framework Preset: **Other**, Build Command і Output Directory залиште порожніми.
3. **Deploy**. Кожна зміна в репозиторії автоматично оновлює сайт.

На комп'ютері сайт показує телефон у рамці, на iPhone — відкривається на весь екран.

## iOS-застосунок

Нативна версія написана на **SwiftUI** (iOS 17+) і збирається в Xcode окремо — Vercel її не запускає. Для публікації в App Store потрібен Apple Developer акаунт.
